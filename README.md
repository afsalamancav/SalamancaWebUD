# Sistema de Registro de Aspirantes - Universidad Distrital

Este repositorio contiene los proyectos y actividades prácticas desarrollados para la asignatura de **Programación Avanzada** en la **Universidad Distrital Francisco José de Caldas**.

## Proyecto 1: Registro de Aspirantes (A1)
Es una aplicación web orientada a la gestión y simulación de inscripciones universitarias aplicando estándares empresariales.

### Arquitectura y Tecnologías Utilizadas
El proyecto está estructurado bajo el patrón de diseño **MVC (Modelo-Vista-Controlador)** separado estrictamente por capas:
* **Vista (Front-End):** Páginas dinámicas utilizando **Jakarta Faces 4.0 (JSF)** y archivos `.xhtml` con diseño responsivo basado en CSS puro.
* **Controlador:** Managed Beans encapsulados bajo el entorno transaccional y de sesión (`@SessionScoped`).
* **Modelo:** Implementación de persistencia simulada en memoria usando estructuras de datos con patrones **DTO** (Data Transfer Object) y **DAO** (Data Access Object).
